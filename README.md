# Loan Intelligence Platform

An end-to-end AI-powered Loan Decision Intelligence Platform designed to support data-driven credit risk assessment, loan default prediction, and explainable lending decisions.

**Currently brewing up my thoughts for further implementation**

## Current Progress

- Integrated and explored the Home Credit Default Risk dataset.
- Completed multi-table feature engineering and customer-level feature aggregation.
- Implemented data validation, missing-value handling, categorical encoding, and feature selection.
- Built a modular model training and evaluation pipeline.
- Trained and benchmarked five classification algorithms: Logistic Regression, Random Forest, XGBoost, LightGBM, and CatBoost.
- Identified LightGBM as the current leading model, with a validation ROC-AUC of 0.7839 and PR-AUC of 0.2832.
